# MQLAuthの仕組み

MQLAuthは、データベースサーバを利用し、データベース上にEA等 [[1]](#note-name-1)
の情報、口座番号等 [[2]](#note-name-2)
の情報を保存することで、遠隔的に口座番号縛り等 [[3]](#note-name-3)
を実装することを実現しています。
