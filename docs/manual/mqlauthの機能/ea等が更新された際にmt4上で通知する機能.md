# アップデート通知機能

MQLAuthはEA等のバージョン情報とダウンロードURLを記録することができます。これを利用することで、EA等のバージョンアップを行った際、古いEA等を動かしているMT4に対しAlert()で更新を通知したり、ダウンロードURLを通知したりすることができます。
