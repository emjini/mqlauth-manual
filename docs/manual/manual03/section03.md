# MQLAuthインクルードファイルのダウンロード

## ファイルのダウンロード

MQLAuthのインクルードファイル(.mqh)をダウンロードし、指定のフォルダに入れます。

- [[最新版 Ver.1.08(2022/06/03) ダウンロード] MQLAuth\_108.zip](https://mql-auth.com/files/MQLAuth_108.zip)
- [[Ver.1.07(2020/12/18) ダウンロード] MQLAuth\_107.zip](https://mql-auth.com/files/MQLAuth_107.zip)
- [[Ver.1.06(2020/12/09) ダウンロード] MQLAuth\_106.zip](https://mql-auth.com/files/MQLAuth_106.zip)
- [[Ver.1.05(2020/11/29) ダウンロード] MQLAuth\_105.zip](https://mql-auth.com/files/MQLAuth_105.zip)
- [[Ver.1.04(2020/11/11) ダウンロード] MQLAuth\_104.zip](https://mql-auth.com/files/MQLAuth_104.zip)
- [[Ver.1.03(2020/11/06) ダウンロード] MQLAuth\_103.zip](https://mql-auth.com/files/MQLAuth_103.zip)
- [[Ver.1.02(2020/10/18) ダウンロード] MQLAuth\_102.zip](https://mql-auth.com/files/MQLAuth_102.zip)
- [[Ver 1.01(2020/10/12) ダウンロード] MQLAuth\_101.zip](https://mql-auth.com/files/MQLAuth_101.zip)
- [[Ver 1.00(2020/09/20) ダウンロード] MQLAuth\_100.zip](https://mql-auth.com/files/MQLAuth_100.zip)

MQLAuthを使うために必要なインクルードファイル(.mqh)と、MQLAuthのサンプルコードが入った圧縮ファイルです。  
サンプルコードはMQL4用のフォーマット”.mq4″になっていますが、”.mq5″にリネームするだけでMQL5でも使用できます。

## 圧縮ファイルの内容

MQLAuth.zipを解凍すると、Includeフォルダの中に MQLAuth.mqh というファイルがあります。

このMQLAuth.mqhを以下のフォルダにコピーしてください。  
MT4の場合  
　　　[MT4のファイル保存フォルダ]/MQL4/Include/  
MT5の場合  
　　　[MT5のファイル保存フォルダ]/MQL5/Include/
