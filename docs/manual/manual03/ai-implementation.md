# AIアシスタントに実装させる

Claude Code、Cursor、ChatGPT、GitHub CopilotなどのAIコーディングアシスタントを使うと、お手持ちのEA・インジケーターのソースコードへのMQLAuth認証の実装を自動化できます。

MQLAuthでは、AIがそのまま読んで実装できる**AI向け実装ガイド**を公開しています。

- AI向け実装ガイド: <https://manual.mql-auth.com/llms-install.md>

## 事前準備

AIに依頼する前に、以下の3つを済ませておいてください。

1. [MQLAuthへの利用登録](/manual/manual03/section01)と[EA・インジケーターの登録](/manual/manual03/section02)を済ませ、**MQLAuth ID**と**登録したアプリケーション名**を控える
2. [MQLAuth.mqhをダウンロード](/manual/manual03/section03)し、`MQL4/Include/`（MT5の場合は `MQL5/Include/`）に配置する
3. 実装したいEA・インジケーターのソースコード（.mq4 / .mq5）を用意する

## 依頼方法

以下のプロンプトをコピーし、2箇所を自分の情報に書き換えて、ソースコードと一緒にAIに渡してください。

```text
以下の実装ガイドを読んで、私のMQL4/MQL5ソースコードにMQLAuthの認証を実装してください。

実装ガイド: https://manual.mql-auth.com/llms-install.md
（Webにアクセスできない場合は、その旨を伝えてください。ガイドの本文を貼り付けます）

- MQLAuth ID: ここに自分のMQLAuth IDを入れる
- アプリケーション名: ここにMQLAuthに登録した名称を入れる
- 認証方式: 口座番号認証

実装が終わったら、ガイド末尾の「実装後の自己チェックリスト」で実装漏れがないか確認し、
チェック結果を報告してください。
```

- パスワード認証を使う場合は「認証方式」を「パスワード認証」に書き換えてください
- Claude CodeやCursorのようにファイルを直接編集できるAIの場合は、対象の `.mq4` / `.mq5` ファイルを開いた状態で依頼してください
- ChatGPTなどチャット型のAIの場合は、ソースコード全文をプロンプトの後ろに貼り付けてください

## 実装後に必ず確認すること

AIの実装は便利ですが、**最終確認はご自身で行ってください。**

1. MetaEditorでコンパイルし、**0 errors** であることを確認する
2. 「DLLの使用を許可する」をONにしてチャートに適用する
3. MQLAuthに**登録済みの口座番号**で認証成功のログが出て、正常に動作することを確認する
4. **未登録の口座番号**で認証失敗のログが出て、動作しないことを確認する

::: warning 注意
認証がうまく動かないままリリースすると、購入者全員が使えない・逆に誰でも使えてしまう、といった事故につながります。必ず登録済み・未登録の両方の口座で動作確認をしてからリリースしてください。
:::
