# MQLAuthにEAを登録

## ステップ1 EA・インジケーター管理画面に入る

管理画面の左サイドバーから「EA・インジケーター」をクリックします。

[![](/images/v2/dashboard.png)](/images/v2/dashboard.png)

## ステップ2 EA・インジケーターの登録

右上の「＋ EA・インジケーターを登録」をクリックすると登録パネルが開きます。EA・インジケーター名（半角英数とハイフン、アンダーバーのみ）とバージョンを入力し、「登録する」ボタンをクリックします。一斉メッセージ機能はここでは利用しないので説明を省いています。

[![](/images/v2/apps-create.png)](/images/v2/apps-create.png)

## ステップ3 登録完了

登録が完了すると、一覧にカードとして表示されます。

[![](/images/v2/apps-page.png)](/images/v2/apps-page.png)
