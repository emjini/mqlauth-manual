# MQLAuthにEAを登録

## ステップ1 EA・インジケーター登録画面に入る

サイト上部メニューの「ユーザー管理」をクリックします。

[![](/images/2021/07/2021-07-07_18h54_54.png)](/images/2021/07/2021-07-07_18h54_54.png)

## ステップ2 EA・インジケーターの新規登録画面へ

「EA・インジケーターの登録」をクリックします。

[![](/images/2021/07/2021-07-07_18h56_03.png)](/images/2021/07/2021-07-07_18h56_03.png)

## ステップ3 EA・インジケーターの登録

必要事項を記入します。一斉メッセージ機能はここでは利用しないので説明を省いています。

[![](/images/2021/07/2021-07-07_18h58_25.png)](/images/2021/07/2021-07-07_18h58_25.png)

## ステップ4 登録完了

これで登録が完了しました。

[![](/images/2021/07/2021-07-07_19h05_14.png)](/images/2021/07/2021-07-07_19h05_14.png)
