# MQLAuthに口座縛りをする口座番号を登録

## ステップ1 ユーザー管理画面へ入る

管理画面の左サイドバーから「ユーザー管理」をクリックし、右上の「＋ ユーザーを登録」をクリックします。

[![](/images/v2/users-page.png)](/images/v2/users-page.png)

## ステップ2 ユーザーの登録

登録パネルが開くので、ユーザー名・口座番号・対象のEA・インジケーター・利用期限などを入力し、「登録する」ボタンをクリックします。

[![](/images/v2/users-create-filled.png)](/images/v2/users-create-filled.png)

## ステップ3 登録完了

一覧にユーザーが表示されれば、口座認証をする口座番号の登録は完了です。MT4/MT5でインジケーターを動かしてみてください。DLL許可にチェックを入れるのを忘れずに。

[![](/images/v2/users-page.png)](/images/v2/users-page.png)
