# MQLAuthに口座縛りをする口座番号を登録

## ステップ1 認証追加画面へ入る

サイト上部メニューの「ユーザー管理」をクリックします。

[![](/images/2021/07/2021-07-07_18h54_54.png)](/images/2021/07/2021-07-07_18h54_54.png)

## ステップ2 新規ユーザー登録画面へ

「ユーザーの登録」をクリックします。

[![](/images/2021/07/2021-07-07_19h36_06.png)](/images/2021/07/2021-07-07_19h36_06.png)

## ステップ3 ユーザーの登録

各項目を入力し、「ユーザー追加」ボタンをクリックします。

[![](/images/2021/07/2021-07-07_19h37_11.png)](/images/2021/07/2021-07-07_19h37_11.png)

## ステップ4 登録完了

これで口座認証をする口座番号の登録が完了しました。MT4でインジケーターを動かしてみてください。DLL許可にチェックを入れるのを忘れずに。

[![](/images/2021/07/2021-07-07_19h42_15.png)](/images/2021/07/2021-07-07_19h42_15.png)
