# 有料プラン利用料金

| 登録数 | 料金 |
| --- | --- |
| 5人以下 | 無料 |
| 6~20人 | 1,650円 |
| 21~30人 | 2,200円 |
| 31~50人 | 3,300円 |
| 51~100人 | 5,500円 |
| 101人~ | 6,050円~ |

口座登録数が500人を超えるなどの大規模な企業様などは、別途ご契約いただくことで、通常の有料プランより割安なエンタープライズプランをご利用可能です。

[エンタープライズプランをご希望の方はこちらよりお問い合わせください。](https://mql-auth.com/Home/Contact)
