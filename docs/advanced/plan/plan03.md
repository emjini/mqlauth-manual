# 有料プランのご請求日

毎月末時点での口座番号登録数を基準に料金が決定し、翌月初めごろに弊社より請求のご案内を通知いたします。

通知に記載の期限までにお支払いをお済ませください。

お支払い方法は、銀行振込またはPayPal決済です。

料金の一例

2021年7月15日時点：口座番号登録数 35件（推定利用料金 3,300円）（この時点では料金未確定）

2021年7月31日時点：口座番号登録数 29件（利用料金が2,200円で確定）

2021年8月1日　2,200円の請求通知を送付、支払期限 2021年8月10日

当月の推定利用料金はマイページから確認することができます。
