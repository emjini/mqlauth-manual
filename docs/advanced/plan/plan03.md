# 有料プランのお支払い

有料プラン（Standard／Unlimited）のお支払いは、**クレジットカードによる月額の自動決済**です。

## 支払方法

クレジットカード決済（月額の自動決済）です。決済手数料などの追加費用はかかりません。表示価格はすべて税込みです。

## 支払時期

本サービスは**前払い制**です。有料プランのお申し込み時に初回分を決済し、以降は毎月の契約更新日に自動的に決済されます。

## 返金について

サービスの性質上、理由に関わらずお支払い後の返品・返金はお受けできません。日割りでの返金も行っておりません。

::: tip
以前の「毎月末の登録ユーザー数に応じた従量課金・後払い」から、2026年8月1日より定額前払い制に変わりました。従量課金プランをご利用中の方には、移行のご案内を個別にお送りしています。
:::
