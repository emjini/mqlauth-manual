# 無料・有料プランの範囲

MQLAuthのほとんどの機能は無料で利用することができます。

例えば、MQLAuthインクールドファイル（MQLAuth.mqh）をダウンロードして使用できるMQLAuthライブラリの機能は全て無料です。

また、口座番号認証・パスワード認証のユーザー登録数が5件以下の場合も無料です。

MQLAuthは、口座番号認証・パスワード認証のユーザー登録数が6件以上の場合のみ料金が発生します。

|  | 料金 |
| --- | --- |
| 口座番号認証登録数（5件以下） | 無料 |
| 口座番号認証登録数（6件以上） | 有料 |
| MQLAuthライブラリの機能 | 無料 |
