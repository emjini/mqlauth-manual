# 無料・有料プランの範囲

MQLAuthは、**登録ユーザー数**によってプランが分かれています。機能そのものはすべてのプランで共通で、口座番号認証・パスワード認証・体験版・一斉／個別メッセージ・アップデート通知・アクセス統計などをどのプランでも利用できます。

MQLAuthインクルードファイル（MQLAuth.mqh）をダウンロードして使うライブラリの機能も、すべて無料です。

登録ユーザー数が **5名まで** であれば、**Freeプラン**として無料でご利用いただけます。6名以上を登録する場合は、有料プラン（Standard／Unlimited）をお申し込みください。

| プラン | 登録ユーザー数 | 月額（税込） |
| --- | --- | --- |
| Free | 5名まで | 無料 |
| Standard | 50名まで | 2,980円 |
| Unlimited | 無制限 | 5,980円 |

::: tip
EA・インジケーターの登録数は、すべてのプランで無制限です。また、**体験版ユーザーは登録ユーザー数のカウントに含まれません**。
:::

各プランの詳しい内容や申し込みは、管理画面の「[料金プラン](/advanced/webservicemanual/plans)」ページからご確認いただけます。
