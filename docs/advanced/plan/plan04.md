# 有料プランの解約

有料プランを解約する（料金が発生しなくなる）方法は以下の3つあります。

- 口座番号登録数を5件以下にする
- MQLAuthアカウントを休止状態にする
- MQLAuthアカウントを削除する

## 口座番号登録数を5件以下にする

口座番号登録数を5件以下にすることで、有料プランでも料金が発生しなくなります。

## MQLAuthアカウントを休止状態にする

アカウントを休止状態にすることで、口座番号登録数を減らさないまま料金の発生を防ぐことができます。この場合は登録された口座番号は有効なままですが、編集ができなくなります。アカウントの休止については[サポートまでお問い合わせください](https://mql-auth.com/Home/Contact)。

## MQLAuthアカウントを削除する

アカウントを削除することで、料金が発生しなくなります。この場合は登録された口座番号は全て無効になりますのでご注意ください。アカウントの削除については[サポートまでお問い合わせください。](https://mql-auth.com/Home/Contact)
