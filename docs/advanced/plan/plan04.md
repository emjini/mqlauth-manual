# 有料プランの解約

有料プラン（Standard／Unlimited）の解約はいつでも可能です。

## 解約の方法

解約をご希望の場合は、[お問い合わせフォーム](https://mql-auth.com/Home/Contact)よりご連絡ください。

## 解約後の扱い

- 解約後も、**お支払い済み期間の終了までは有料プランの機能をご利用いただけます**。
- 期間終了後は、**無料プラン（登録ユーザー5名まで）に自動的に移行**します。
- **登録済みのユーザーデータが消えることはありません**（そのまま保持されます）。

## 登録ユーザーが6名以上ある状態で無料プランに移行した場合

有料プランで6名以上のユーザーを登録していた状態のまま無料プランに移行すると、**登録済みのすべてのユーザーが「閲覧・削除のみ」**の状態になります。具体的には、以下の操作ができなくなります。

- ユーザー情報の編集
- 利用期限の延長・失効
- 新規ユーザーの登録・体験版ユーザーの本登録

一方で、以下は引き続き行えます。

- ユーザー一覧・登録内容の閲覧
- ユーザーの削除
- **登録済みユーザーの認証そのものは有効なまま**（利用者側のEA・インジケーターは引き続き利用できます）

登録ユーザーを削除して5名以下にするか、有料プランを再開すると、通常どおり編集・延長・登録が行えるようになります。**この間も登録データが失われることはありません。**

::: tip
これは、有料プランを解約したあとも登録データを安全に保ちつつ、無料プランの範囲（5名まで）に収まるよう促すための仕組みです。「6名以上のうち先頭5名だけ編集できる」といった部分的な編集はできません（全ユーザーが一律で閲覧・削除のみになります）。
:::

## アカウントの削除

アカウントそのものの削除をご希望の場合も、[お問い合わせフォーム](https://mql-auth.com/Home/Contact)よりご連絡ください。
