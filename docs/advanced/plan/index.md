# 料金・有料プラン

MQLAuthの料金プラン（Free／Standard／Unlimited）や、お支払い・解約についてご案内します。有料プランのご利用予定の方は、下記をご確認のうえご検討ください。

2026年8月1日より、料金体系はクレジットカードによる月額自動決済の**定額制**になりました。プランの確認・お申し込みは、管理画面の「[料金プラン](/advanced/webservicemanual/plans)」ページから行えます。
