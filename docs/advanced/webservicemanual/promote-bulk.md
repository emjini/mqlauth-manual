# 体験版ユーザーの一括通常化

[EA・インジケーターの管理](/advanced/webservicemanual/applications)ページから、特定のEA・インジケーターの体験版ユーザーを、まとめて通常の登録ユーザーへ変更できます。

体験版ユーザーを1名ずつ通常化する方法は[ユーザー管理](/advanced/webservicemanual/users)をご覧ください。人数が多い場合は、こちらの一括操作が便利です。

## 使い方

1. 「EA・インジケーターの管理」ページを開きます
2. 対象のEA・インジケーターのカードにある **「体験版 N件」** のブロックをクリックします
   （マウスを乗せると「体験版 → 通常化」と表示されます。体験版が0名の場合はクリックできません）
3. 確認画面が開き、**対象とスキップの内訳**が表示されます
4. 内容を確認し、**「通常化する（N名）」** ボタンを押すと実行されます

## 確認画面の見方

実行前に、体験版ユーザーが以下のように分類されて表示されます。

- **✓ 通常化される** … 実際に通常ユーザーへ変更される人数です
- **⏭ 期限切れ（対象外）** … 利用期限を過ぎている体験版です。一括操作の対象外です
- **⏭ 同口座に通常ユーザー既存** … 同じ口座番号の通常ユーザーがすでに登録されている体験版です
- **⏭ 過去に移行済み** … 以前この機能などで通常ユーザーへ移行した記録が残っている体験版です
- **⛔ プラン上限で不可** … 料金プランの登録ユーザー数の上限に達したため、通常化できなかった人数です。あわせて「通常ユーザー ◯／◯ 名」と現在の登録数と上限が表示されます

「通常化される」が0名のときは、ボタンが「通常化できる対象がありません」となり実行できません。

## 通常化したあとの扱い

- 通常化されたユーザーは、**料金プランの登録ユーザー数にカウントされます**
- 利用期限はそのまま引き継がれます
- 元の体験版レコードは削除されず、**期限切れの状態で残ります**。これは同じ口座番号で体験版を再取得されるのを防ぐための記録です

## 知っておいていただきたいこと

### 期限切れの体験版は対象になりません

一括操作は**有効期限内の体験版のみ**を対象とします。期限切れの体験版まで通常化すると、すでに使われていない口座で料金プランの登録枠が埋まってしまうためです。

期限切れの体験版を意図的に通常化したい場合は、[ユーザー管理](/advanced/webservicemanual/users)から個別に「通常化」してください。

### 上限の判定はアカウント全体で行われます

「プラン上限で不可」の判定に使われる通常ユーザー数は、**そのEA・インジケーター単体ではなく、お客さまのアカウントに登録されている全EA・インジケーターの合計**です。他のEAで登録枠を使っている場合、対象のEAの体験版が少なくても上限に達することがあります。

Unlimitedプランをご契約の場合は上限がないため、この行は表示されません。

### 上限に達した場合は登録の古い順に通常化されます

通常化できる人数が残りの登録枠を超えている場合、**登録の古い体験版から順に**枠の分だけ通常化され、残りは「プラン上限で不可」として扱われます。特定のユーザーを優先したい場合は、先に[ユーザー管理](/advanced/webservicemanual/users)から個別に通常化してください。

### 同じ口座番号の体験版が複数ある場合

同一のEA・インジケーターに同じ口座番号の体験版が複数登録されている場合、通常化されるのは**登録の古い1件のみ**です。残りは「同口座に通常ユーザー既存」として扱われます。

::: warning 実行前に内訳をご確認ください
一括通常化は取り消しができません。通常化されたユーザーを体験版に戻すことはできない仕様のため、実行前に確認画面の内訳、特に「✓ 通常化される」の人数を必ずご確認ください。
:::
