# 有料プランへの移行方法

有料プラン（Standard／Unlimited）へのお申し込みは、MQLAuth管理画面へログイン後、左サイドバーの「**料金プラン**」ページから行えます。

[![](/images/v2/console-plans.png)](/images/v2/console-plans.png)

各プランの内容をご確認のうえ、ご希望のプラン（Standard／Unlimited）のボタンからお申し込みください。お申し込みフォームにクレジットカード情報を入力すると、毎月の自動決済が始まります。

::: warning お申し込み受付開始について
有料プランのお申し込み受付は、**2026年8月1日に開始**します。それまでは各プランのボタンに「8月1日 受付開始」と表示されます。7月中は引き続き、無料のまま全機能をご利用いただけます。
:::

お申し込み後は、ダッシュボードの「現在のプラン」がお申し込みいただいたプランになっていることをご確認ください。

- お支払いの時期・返金については「[有料プランのお支払い](/advanced/plan/plan03)」をご覧ください。
- 解約については「[有料プランの解約](/advanced/plan/plan04)」をご覧ください。
- 請求に関するメールアドレスを変更したい場合は「[登録メールアドレスの変更方法](/advanced/webservicemanual/web002)」をご参考ください。

なお、登録ユーザー数が5名までの場合は、無料のFreeプランのままでもすべての機能をご利用いただけます。
