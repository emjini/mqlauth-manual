# 有料プランへの移行方法

有料プランへの変更は、MQLAuth管理画面へログイン後、マイページに入り、登録情報の右下「有料プランに変更する」ボタンから可能となっております。

[![](/images/2021/07/image001.png)](/images/2021/07/image001.png)

登録情報と確認事項が表示されますので、よくお読みになり、「有料プランへ変更する」ボタンを押してください。請求書が送られるメールアドレスを変更したい場合は[「登録メールアドレスの変更方法」](/advanced/webservicemanual/web002 "登録メールアドレスの変更方法")をご参考ください。

[![](/images/2021/07/2021-07-14_10h04_31.png)](/images/2021/07/2021-07-14_10h04_31.png)

有料プランへ変更後、同じくマイページの登録情報の「現在のプラン」が「有料プラン」になっていることをご確認ください。

[![](/images/2021/07/image002.png)](/images/2021/07/image002.png)

なお、有料プランへ変更したとしても、口座番号登録数が5個以下の場合は費用は発生しませんので、ご安心ください。
