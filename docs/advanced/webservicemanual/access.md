# アクセス統計の見方

EA・インジケーターが認証サーバーへ問い合わせた回数（認証リクエスト）の推移を確認できるページです。利用者の活動状況の把握にお使いいただけます。

[![](/images/v2/console-access.png)](/images/v2/console-access.png)

## サマリーカード

上部に、直近30日間の集計が表示されます。

- **30日間の総認証リクエスト数** … 直近30日の認証リクエストの合計
- **30日間のユニークユーザー数** … 期間内に認証を行ったユーザーの実数
- **日平均リクエスト数** … 1日あたりの平均リクエスト数
- **本日のリクエスト数** … 当日分のリクエスト数

## 日別推移（直近30日）

日ごとの認証リクエスト数を棒グラフで表示します。

- 右上のボタンで「**認証リクエスト数**」と「**ユニークユーザー数**」の表示を切り替えられます。
- 「すべてのEA・インジケーター」のプルダウンで、特定のEA・インジケーターだけに絞り込めます。
- 各バーにカーソルを合わせると、その日の日付と値が表示されます。

## EA・インジケーター別（30日合計）

直近30日の認証回数とユニークユーザー数を、EA・インジケーターごとに集計して表示します。どのEA・インジケーターがよく使われているかを比較できます。

::: tip 集計について
集計は認証サーバーへのアクセス数（日次）を元にしています。EA・インジケーターの認証実装によって、1日あたりのアクセス頻度は変わります。
:::
