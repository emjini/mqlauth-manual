# EA・インジケーターの管理

認証を組み込むEA・インジケーターを登録・管理するページです。登録したEA・インジケーターごとに、ユーザー数や認証回数を確認できます。

[![](/images/v2/console-apps.png)](/images/v2/console-apps.png)

## 一覧（カード表示）

登録済みのEA・インジケーターがカード形式で並びます。各カードには、以下の情報とボタンが表示されます。

- **バージョン** … 現在の最新バージョン番号（右上）
- **ユーザー** … そのEA・インジケーターの通常ユーザー数
- **体験版** … 体験版ユーザー数。ここをクリックすると、そのEA・インジケーターの体験版ユーザーを[まとめて通常ユーザーへ変更](/advanced/webservicemanual/promote-bulk)できます
- **週間認証** … 直近1週間の認証リクエスト数
- **ユーザーを見る** … そのEA・インジケーターで絞り込んだ[ユーザー管理](/advanced/webservicemanual/users)へ移動します
- **編集** … 編集パネルを開きます（下記）
- **統計** … そのEA・インジケーターで絞り込んだ[アクセス統計](/advanced/webservicemanual/access)へ移動します

一覧上部の検索ボックスで、EA・インジケーター名による絞り込みができます。

## 新規登録

右上の「＋ EA・インジケーターを登録」ボタンから、新しいEA・インジケーターを登録できます。

## EA・インジケーターの編集

「編集」ボタンをクリックすると、画面右側に編集パネルが開きます。

[![](/images/v2/console-apps-edit.png)](/images/v2/console-apps-edit.png)

- **EA・インジケーター名** … 認証に使う名称です（半角英数・「・」「-」「_」）。
- **最新バージョン番号** … アップデート通知機能で利用者に知らせるバージョンです。
- **体験版の自動作成** … 有効にすると、利用者がEAをチャートに挿入した際に自動的に体験版ユーザーが作成されます。
- **ダウンロードURL** … アップデート通知の際に利用者に案内するURLです。
- **一斉メッセージ** … 全利用者のチャート上に表示するメッセージです。表示開始・終了の期間も指定できます。

::: warning 名前の変更にご注意
EA・インジケーター名を変えると、旧名称で実装・配布済みのEAの認証が通らなくなります。すでに配布済みのEAがある場合は変更しないでください。
:::
