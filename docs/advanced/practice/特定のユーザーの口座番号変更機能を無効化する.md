# 特定のユーザーの口座番号変更機能を無効化する

ユーザーの口座変更機能は、MQLAuthに登録されたメールアドレスと口座番号の照合により行っています。ユーザー管理画面の編集パネルで、口座番号変更を無効化したいユーザーのメールアドレス欄にお好きな文字列を追加する（実在しないアドレスにする）ことで、そのユーザーは口座番号を変更できなくなります。

[![](/images/v2/users-edit.png)](/images/v2/users-edit.png)

なお、体験版ユーザーはこの設定に関わらず、口座番号の変更が常にできない仕様です。
