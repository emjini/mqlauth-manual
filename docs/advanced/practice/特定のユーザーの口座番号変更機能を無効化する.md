# 特定のユーザーの口座番号変更機能を無効化する

ユーザーの口座変更機能は、MQLAuthのメールアドレスと口座番号の照合により行っています。MQLAuth管理画面上で、口座番号変更を無効化したいユーザーのメールアドレスにお好きな文字列を追加することで、ユーザーからは口座番号を変更できなくすることが可能です。
